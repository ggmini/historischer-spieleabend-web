## File Structure  
`data.yaml`         Potential topics for future evenings should be put in this file.  
`data_draft.yaml`   Unfinished Drafts for topics should be put here.  
`data_past.yaml`    This file is for topics that we have already done, so they don't clutter up the the main file. I will move any old topics into this file whenever the I update the next evening's topic.  
`template.yaml`     This file has a template for what the yaml structure should look like in the other files.
